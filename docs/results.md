# Отчёт по задаче №4 Qildo

Здесь сохранены результаты предыдущей версии. Текущий протокол, сравнение и команды находятся в [новом отчёте](experiments-v3.md).

## Сравнение с предыдущей версией

Beat F1 и Downbeat F1 измерены с допуском ±70 мс от нулевой секунды. В каждой строке обе версии проверены на одинаковых файлах. Синтетические миксы вынесены отдельно.

| Набор и конфигурация | Записей | Beat F1 | Downbeat F1 | CMLt |
| --- | ---: | ---: | ---: | ---: |
| GuitarSet · прежняя CNN | 72 | 57,27% | 25,32% | 42,41% |
| GuitarSet · новая residual CNN и декодер | 72 | **60,24%** | **34,75%** | **50,05%** |
| Groove MIDI · прежняя CNN | 10 | 40,92% | 32,37% | 25,50% |
| Groove MIDI · новая residual CNN и декодер | 10 | **79,41%** | **60,86%** | **66,49%** |
| Nullsample · прежний акустический трекер | 20 | 52,32% | 38,63% | 31,77% |
| Nullsample · новый акустический трекер | 20 | **82,03%** | **67,00%** | **79,79%** |
| Собственные синтетические миксы · прежний акустический трекер | 12 | 99,87% | 79,75% | 99,82% |
| Собственные синтетические миксы · новый акустический трекер | 12 | 99,87% | **82,16%** | 99,82% |

На GuitarSet ошибка первой доли осталась на уровне **4 из 72**. Число тактов с соседним сдвигом акцента на общем подмножестве упало с **80 до 37 из 267**. Ошибки ×2/÷2 сократились с **74 до 58 из 984** тактов. На Groove MIDI первая доля улучшилась с 1 ошибки до 0, а ошибки ×2/÷2 — с 86 до 70 тактов. На Nullsample число тактов с ×2/÷2 снизилось с **607 до 2 из 1372**, при этом ошибок первой доли стало больше, **3 → 7 из 20**.

## Что дало эффект

- На валидации GuitarSet старый классификатор при заданных эталонных временах всех долей даёт 64,7% Downbeat F1. С прежней CNN, но совместным декодером, Downbeat F1 вырос с 27,2% до 35,2%. Декодер уменьшает потери, которые возникают при независимом выборе пульса и точки начала такта. [Исследование совместного декодирования](https://www.cp.jku.at/research/papers/Boeck_etal_ISMIR_2016.pdf)
- Residual CNN, обученная только на гитарных данных, достигла минимума validation loss на третьей эпохе и затем переобучалась. На GuitarSet расширение набора барабанными записями улучшило итоговые результаты, хотя конфигурации по-разному влияли на качество пульса и акцента.
- Модель, обученная на гитаре и ударных, уступила акустическому режиму на электронных миксах Nullsample. Поэтому для электронных треков стоит отдельно замерять конфигурацию без весов. Nullsample и собственные синтетические миксы использовались при разработке акустической ветки. Оценка на них диагностическая.
- Смена размера происходит на границе такта. Регрессионный тест проверяет переход 4/4 → 3/4. На синтетическом миксе с несколькими сменами размера новый трекер набрал 100% Beat F1 и 91,1% Downbeat F1.

## Данные и воспроизводимость

- GuitarSet v1.1.0, CC BY 4.0. 216 обучающих, 72 валидационных и 72 тестовых гитарных фрагмента, разбиение по музыкальной основе. Тест содержит три музыкальные основы. [GuitarSet](https://zenodo.org/records/3371780)
- Groove MIDI Dataset v1.0.0, CC BY 4.0. Для опубликованной модели использован список из 121 записи. 101 запись для обучения, 10 для валидации, 10 для теста. Тестовый барабанщик отсутствует в обучении. MIDI-сетка привязана к началу исполнения и обрезана по длине MIDI/WAV. Это исполнения ударных под клик. [Groove MIDI Dataset](https://magenta.withgoogle.com/datasets/groove)
- Nullsample, CC BY 4.0. 20 полных синтетических электронных миксов с разметкой из авторской партитуры, ревизия `3b22000b2f3dffc69b9d7654ca62e53f1b153754`. [Nullsample, Maqsudjon Polatov](https://huggingface.co/datasets/Maqsudjonpolatov/nullsample-multitrack)

```bash
python -m pip install -e '.[eval,ml,data,dev]'
python prepare_groove.py data/downloads/groove-v1.0.0-midionly.zip data/downloads/groove data/groove \
  --selection benchmarks/groove-121.csv
python train.py data/guitarset/manifest.json runs/reproduce.pt \
  --additional-manifest data/groove/manifest.json --architecture residual \
  --augment --channels 24 --batch-size 16 --epochs 14 --seed 2026
python evaluate.py manifest data/guitarset/manifest.json runs/baseline-test.json \
  --split test --decoder sequence --checkpoint checkpoints/guitarset-demo.pt \
  --save-predictions runs/baseline-test
python evaluate.py manifest data/guitarset/manifest.json runs/candidate-test.json \
  --split test --checkpoint checkpoints/mixed-residual.pt --compare runs/baseline-test
```

Опубликованные веса `checkpoints/mixed-residual.pt` соответствуют эпохе 12, validation loss 0,82570. SHA-256 — `cb05cda6474e2ee9a5960ccfdbf3300be98e32977b80c1efd25062afb35c08c8`. Обучение начиналось со случайных весов.

## Офлайн-инференс

На CPU Apple M4 в контейнере Linux ARM64 с отключённой сетью проверены три WAV по 240 секунд. На каждой записи измерено полное время команды, включая чтение аудио, загрузку модели и запись JSON.

| Конфигурация | Худшее время | Пик RSS |
| --- | ---: | ---: |
| Акустический трекер | 4,08 с | 279 МиБ |
| Residual CNN и декодер | 6,22 с | 319 МиБ |

Одна из записей для замера — первые 240 секунд *Inspired*, Kevin MacLeod, CC BY 4.0. Запись преобразована в WAV 44,1 кГц, стерео. Для неё измеряли только время и проверяли формат JSON. [Источник и лицензия Inspired](https://incompetech.com/music/royalty-free/index.html?isrc=USUAN1600022)

## Границы выводов

На GuitarSet достигнуты цели по приросту Beat F1, Downbeat F1 и CMLt относительно прежней CNN. Уменьшение ошибок ×2/÷2 на этом наборе составляет 22% при цели 50%. GuitarSet мал по числу независимых музыкальных основ, Groove MIDI — по числу тестовых барабанщиков. Прогон обучения выполнен с фиксированным seed 2026. Синтетический набор показывает работу на конкретных переходах и аранжировках. Для оценки продуктового качества нужны независимые полные песни с ручной разметкой и слепая проверка Qildo.
